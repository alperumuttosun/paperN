
# Negative Transfer in Multi-Country Crop-Yield Prediction — Code & Data

This repository contains the R pipeline behind the paper *"Negative Transfer in
Multi-Country Crop-Yield Prediction: Prevalence, Predictability, and Its Limits
Across Crops."*

## Getting started

- **Input data:** `panelv7_<crop>.xlsx` — one file per crop (wheat, barley,
  oats, rye, rice, maize, soybean, sorghum), containing the country-year
  panel used throughout the analysis.
- **Figures:** the manuscript's figures (Figure 1, Figure 2, Figure A1) are
  included as ready-made files; they are also regenerated by Steps 8 and 12
  below if you re-run the pipeline.
- **Step 00** (better to skip) downloads and assembles the raw
  panel data from source. It is slow and is **not required** to reproduce the
  analysis or the paper's results. **Start directly with Step 1** using the
  provided `panelv7_<crop>.xlsx` files.

Each step reads the previous steps' Excel output(s) and writes its own
`negstepN_output.xlsx`, so the steps must be run in order the first time.
Step numbering skips 6 and jumps from 5 to 7: an early version of Step 7 used
to depend on a separate Step 6 (a richer, 12-variable country fingerprint);
Step 6 was later found to be redundant and dropped, but the numbering from
the review process was kept as-is for traceability.

## Pipeline overview

| Step | Script | What it does | Output |
|---|---|---|---|
| 1 | `negatifstep1.R` | Selects, for every crop, the target countries (5, via k-means), the fixed source pool (N = 20), and the remaining candidate countries. | `negstep1_output.xlsx` |
| 2 | `negatifstep2.R` | Fits LASSO and XGBoost yield models and computes NT(s\|S,t) — the change in target error from adding each candidate — for every (target, candidate) pair. | `negstep2_output.xlsx` |
| 3 | `negatifstep3.R` | Computes the pool-aware distance D_pool(s,S,t) and checks whether it tracks NT better than the plain pairwise distance from Step 2. | `negstep3_output.xlsx` |
| 4 | `negatifstep4.R` | Tests whether a classifier can predict I(NT<0) from the distance features, under random, (crop,target)-grouped, and fully corrected country-grouped cross-validation. | `negstep4_output.xlsx` |
| 5 | `negatifstep5.R` | Leave-one-crop-out (LOCO) validation with the basic distance features, to check whether any signal generalizes across crops. | `negstep5_output.xlsx` |
| 7 | `negatifstep7.R` | Adds pool-composition features on top of Step 4's distances, re-runs LOCO, and runs the crop-stratified permutation test. | `negstep7_output.xlsx` |
| 8 | `negatifstep8.R` | Draws Figure 1 (% negative transfer by crop) and Figure 2 (LOCO AUROC), in each crop's own color, saved as PDF/PNG/TIFF. | `fig1_pct_negative.*`, `fig2_loco_auroc.*` |
| 9 | `negatifstep9.R` | Appendix robustness check: adapts LogME, an established transferability metric from the literature, to this setting and compares it to the Mahalanobis-based measures. | `negstep9_output.xlsx` |
| 10 | `negatifstep10.R` | LOCO validation and permutation test for the LogME-based measure from Step 9, using the same protocol as Steps 5 and 7. | `negstep10_output.xlsx` |
| 11 | `negatifstep11.R` | Sensitivity check: recomputes the headline prevalence statistic across different pool sizes and random seeds. | `negstep11_output.xlsx` |
| 12 | `negatifstep12.R` | Draws Figure A1 (Appendix A), the LOCO AUROC figure for the LogME-based measure, in the same style as Figure 2. | `figA1_*.*` |

## Notes

- All steps are combined in `negatif_full.R` for convenience, except Step 12,
  which is a separate script.
- Re-running any step overwrites its own output file only; steps downstream
  of it should be re-run afterward to pick up the change.
